# EduGenie – Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant developed as a Naan Mudhalvan project.

## Features

- Question & Answer
- Topic Explanation
- Quiz Generation
- Text Summarization
- Personalized Learning Path

## Technologies Used

- Python
- FastAPI
- Google Gemini API
- Hugging Face Transformers
- LaMini-Flan-T5-783M
- HTML
- CSS
- Jinja2
